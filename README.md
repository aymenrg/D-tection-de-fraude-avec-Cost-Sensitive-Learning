# D-tection-de-fraude-avec-Cost-Sensitive-Learning
Projet de détection de fraude sur données déséquilibrées utilisant PCA, Tomek Links et Cost-Sensitive Learning. Entraînement et optimisation de modèles Decision Tree et XGBoost via GridSearch pour améliorer le rappel sur les transactions frauduleuses et réduire les faux négatifs.
